# Detective AI — Hackathon Game Plan
> 7 hours · 3–4 people · Web game with procedural world + voice AI NPCs

---

## Concept

A noir detective game where every case is unique. The player explores a procedurally generated low-poly city, enters their office to pick a case (generated by Gemini), then returns to the city to interrogate AI-powered NPCs — using **real voice** via Gemini Live API. Suspects lie, deflect, and reveal clues. The player must accuse the right person to win.

**Demo pitch in 10 seconds:** *"Talk to suspects out loud. They answer in character. Every case is different. Built in 7 hours."*

---

## Tech Stack

| Layer | Technology | Why |
|---|---|---|
| Frontend framework | React + Vite | Fast setup, component model |
| 3D / Isometric view | React Three Fiber + drei | R3F abstracts Three.js into components |
| 3D Assets | Kenney Mini City Kit (.glb) | Free CC0, low-poly, exactly the right aesthetic |
| State management | Zustand | Simple global game state |
| AI — case generation | Gemini 2.0 Flash | Cheap, fast, generates full JSON world |
| AI — NPC dialogue | Gemini 2.0 Flash | Text fallback + NPC persona system prompts |
| AI — Voice NPCs | **Gemini Live API** | Killer feature — real-time voice dialogue |
| Visual effects | TypeGPU | Neon glow post-processing on buildings |
| Gesture control (bonus) | MediaPipe | Point at suspect to accuse them |
| Deployment | Vercel | One command deploy |

### Zustand Store Shape

```typescript
interface GameState {
  phase: 'menu' | 'office' | 'city' | 'dialogue' | 'resolution'
  currentCase: CaseJSON | null
  activeNPC: NPC | null
  notebook: {
    clues: string[]
    suspicions: string[]
  }
  dialogHistory: { npcId: string; messages: Message[] }[]
  accusation: string | null

  // Actions
  startNewGame: () => void
  enterOffice: () => void
  enterCity: () => void
  interactWithNPC: (npcId: string) => void
  addNote: (note: string) => void
  accuse: (npcId: string) => void
}
```

## NPC System Prompt Template

```
You are {name}, a {occupation} in a noir detective game.

PERSONALITY: {personality}

WHAT YOU KNOW:
{knows_list}

WHAT YOU ARE HIDING:
{hides_list}

YOUR ALIBI: {alibi}

RULES:
- Stay in character at all times. You are a real person, not an AI.
- Never directly admit to what you are hiding unless the detective presents strong evidence.
- You may lie, deflect, get angry, or become scared depending on the question.
- Keep responses to 2-4 sentences. This is a real-time voice conversation.
- If asked something you don't know, say so naturally.
- The detective's name is never mentioned — address them as "detective."
```

## Gemini Prompts

### Case Generation Prompt

```
Generate a noir detective case for a short mystery game.

Return ONLY valid JSON matching this exact schema:
- case: { title, victim: {name, occupation}, location, time_of_death, murder_weapon, motive, solution: {murderer_id, evidence[]} }
- npcs: array of 3 suspects, each: { id, name, occupation, building (one of: bar/apartments/police/warehouse), personality, knows[], hides[], alibi }
- clues: array of 4 physical clues, each: { id, location, description, found: false }
- map_layout: { buildings: [{ type, position: [x,0,z], npc_id }] }

Rules:
- Exactly one NPC is the murderer
- Other NPCs have indirect knowledge but are innocent
- The case should be solvable through dialogue alone (no pixel hunting required)
- Tone: dark, moody, 1950s noir
- NO markdown, NO explanation, ONLY the JSON object
```

## Risk Mitigation

| Risk | Mitigation |
|---|---|
| Gemini Live API rate limits | Pre-test before hackathon, have text fallback ready |
| .glb models too heavy to load fast | Pre-export compressed versions, use Draco compression |
| NPC says wrong things / breaks character | Tighten system prompt, add `temperature: 0.7` |
| 3D scene too slow on jury laptop | Add `<Canvas dpr={1}>` performance cap, test on integrated GPU |
| No time for TypeGPU | Drop it — Gemini Live alone wins |
